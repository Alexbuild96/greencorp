# Resale AI

ИИ-помощник для вторичного рынка: фото вещи → оценка → объявление под нужную площадку → черновик ответа покупателю.
Второй режим (поиск недооценённых лотов для перекупщиков) — в дорожной карте, см. [docs/ROADMAP.md](docs/ROADMAP.md).

## Запуск

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env        # впишите ANTHROPIC_API_KEY
uvicorn app.main:app --reload
```

Откройте http://localhost:8000 — веб-интерфейс (`web/`) отдаётся тем же сервером.
Документация API: http://localhost:8000/docs

## Тесты

```bash
cd backend && python -m pytest -q
```

Тесты не обращаются к API Claude (вызовы подменены).

## Структура

| Путь | Назначение |
|---|---|
| `backend/app/llm.py` | все обращения к Claude (оценка, объявление, ответ) |
| `backend/app/prompts.py` | системные промпты |
| `backend/app/schemas.py` | структуры данных (структурированный вывод) |
| `backend/app/platforms.py` | реестр площадок |
| `backend/app/categories.py` | категории вещей: подсказки для промптов и чек-лист вопросов владельцу |
| `eval/` | шаблон пилота (30 вещей) и `score.py` для расчёта точности оценки |
| `web/` | мобильный веб-интерфейс (загрузка фото, оценка, объявление) |

## Принципы v0.1

- Человек в цикле: публикует и отправляет сообщения сам. Автоматизация — только через официальные API площадок.
- Ответы покупателям: код гарантирует, что цена не опускается ниже минимальной, а подозрительные сообщения помечаются `needs_human`.
- Модель задаётся переменной `CLAUDE_MODEL`.
